**Missing Skills (relative to typical AI/ML internship/entry-level bar)**

- Cloud platforms (AWS/GCP/Azure) — even basic exposure helps significantly
- Model deployment / MLOps basics (e.g., Flask/FastAPI for serving a model, Docker fundamentals)
- Deeper Data Structures & Algorithms — resume currently lists this as "Basic," and DSA rounds are common in technical interviews, even for ML roles
- Quantified project outcomes — your projects describe *what* you built well, but not yet measurable results (accuracy, dataset size, performance gains). This is the single highest-leverage fix available to you right now.
- No internship, hackathon, or open-source contribution listed yet — even one of these significantly strengthens credibility

**Recommended Learning Roadmap**

*Phase 1 (Next 4–6 weeks) — Strengthen the resume you already have*
- Go back into your 3 existing projects and add metrics: dataset size, accuracy/F1 score, latency, or comparison numbers (e.g., "semantic search returned X% more relevant results than keyword search on a test set of Y queries"). This alone will meaningfully upgrade your resume's credibility.
- Learn basic SQL (freeCodeCamp or similar) — a near-universal requirement, even for ML-adjacent roles.

*Phase 2 (2–3 months) — Build depth*
- Pick one deep learning framework (PyTorch is generally the better choice for NLP-leaning profiles) and rebuild one existing project (e.g., resume classifier) using it instead of Scikit-learn alone.
- Sharpen DSA fundamentals — target consistent practice (e.g., 2–3 problems/week) since many entry-level technical screens include a DSA round regardless of ML focus.

*Phase 3 (3–6 months) — Get external validation*
- Contribute to one open-source ML/NLP repository, even a small documentation or bug-fix PR — this diversifies your GitHub beyond solo projects.
- Enter one hackathon or Kaggle competition — gives you a dated, verifiable achievement and often a leaderboard rank to quote.
- Apply for a formal internship — by this point your profile will have measurable project outcomes, one deep learning project, basic SQL, and DSA practice, which is a genuinely strong entry-level AI/ML application.

## SECTION 12: Interview Talking Points

**Most Impressive Achievements to Lead With**
- Completing the 60 Days AI Challenge (ABTalks) end-to-end and publishing every resulting project publicly — proof of consistency, not just one-off effort.
- Building two distinct, non-trivial ML/NLP systems (resume classifier, semantic search) entirely outside of coursework, showing initiative before you were required to.

**Key Stories to Tell**
1. **The Resume Screening System** — Walk through *why* you chose this problem, what preprocessing/tokenization challenges came up, and what you'd improve next (this shows growth mindset, which interviewers value highly in freshers).
2. **Semantic Search vs. Keyword Search** — This is your strongest story: it shows comparative reasoning. Be ready to explain, in plain language, *why* embedding-based search can outperform keyword matching, and what limitations you observed. If asked "how did you evaluate which was better," have a clear answer ready — this is a common follow-up.
3. **The 60-Day Challenge** — Use this to answer "tell me about a time you stayed disciplined without external accountability." It's your best evidence of self-management.

**Areas Recruiters/Interviewers Are Likely to Ask About — Be Ready**
- "You don't have formal work experience — how do we know you can work on a team?" → Have an honest, confident answer ready (e.g., group academic work, open-source plans, willingness to learn fast).
- "What metrics did your models achieve?" → This is currently a gap (see Section 10). Before interviewing, go back and calculate/record real numbers from your projects so you're not caught without an answer.
- Basic DSA / coding questions — expect at least one live coding or logic question even for ML-focused internships.
- "Why AI/ML specifically?" → Prepare a genuine, specific answer beyond "it's the future" — interviewers can tell the difference immediately.
- "What would you do differently if you rebuilt [project]?" → Have one honest answer per project; this signals reflective thinking, which freshers often skip preparing for.
